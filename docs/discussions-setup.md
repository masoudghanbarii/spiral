# Spiral — Discussions Setup Guide

## Recommended Categories

Create these categories in your GitHub Discussions settings
(Repo → Settings → General → Features → Discussions → Categories):

### 1. Announcements (already created)
- **Purpose:** Release notes, project updates, important news
- **Format:** Announcements (only maintainers can post)

### 2. Ideas and Feature Requests
- **Purpose:** Community proposes new features, discusses before opening issues
- **Format:** Discussion (anyone can post)
- **Label:** `idea`

### 3. Q&A
- **Purpose:** Questions and answers — the community helps each other
- **Format:** Q&A (answers can be marked as best answer)

### 4. Show and Tell
- **Purpose:** Users share what they built with Spiral
- **Format:** Discussion (anyone can post)

## Welcome to Spiral Discussions! 

Spiral is an AI co-founder harness built for agents and loops. It runs autonomous development loops — implement, test, fix, repeat — all inside a terminal-native TUI with multi-session support.

### Where to post what

- **Q&A** — Stuck on something? Ask here. Mark the best answer when you get one.
- **Ideas and Feature Requests** — Have an idea? Propose it here before opening an issue.
- **Show and Tell** — Built something cool with Spiral? Share it!
- **Announcements** — Release notes and project updates (maintainers only).
